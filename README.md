# 见声 SeeSound

独立于《回声 Echo》的辅助应用预览工程，版本 0.53。以面对面沟通和声音提醒为主要入口，用“准备、交流、核对、结果”四步串起听障学生的校园窗口办理；沿用端侧字幕、手部检测、iPhone / Watch 回应、沟通模板、卡片互传、本机文件转写、个人声音样本、环境声音实验和可选 DeepSeek 文字整理。真实环境识别和腕上触觉仍需真机验证。

## 0.53：听障学生的窗口办事流程

- 旅程顶部增加“窗口办事 · 按四步继续”，有未结束旅程时，首页与办事页也可直接继续。准备问题与材料、现场逐题交流、核对安排和办理结果集中在同一个入口，切换步骤不会自动确认信息。
- 现场提供沟通方式说明、大字提问、逐题记录回答、字幕与文字回应及交流摘录。字幕在当前导航内打开，返回后继续原旅程；大字展示沿用暂停采集的规则，回到窗口页能看到当前收音状态。
- 已保存的手动回答可预览并选取其中原句，主动同意后建立待核对卡。回答快照保留来源与版本，演示标记不混入普通记录。卡片仍分别由用户核对、记录对方确认。
- 修改或删除回答会使依赖它的旧卡失效并清除确认；旧依据保留供对照，当前核对列表优先显示有效卡片。重复建立相同卡片复用现有记录，过期预览和容量失败不部分写入。
- 办理结果支持“办好了／需要补材料／等待回复”起句、后续事项与主动提醒。回答和结果页增加未保存退出保护；是否结束旅程仍由用户选择。

体验入口、手动检查路线与本轮边界见 [0.53 使用与待验](docs/counter-v053/使用与待验.txt)。本轮只进行构建与相关数据检查，页面点击和真机体验留待后续验证，详见 [0.53 验证记录](docs/counter-v053/验证记录.txt)。

## 0.52：围绕沟通与提醒组织界面

- 主导航调整为“沟通／提醒／办事／我的”，保留奶油粉底色、自绘图标和 Open Doodles 人物。首页首先呈现面对面字幕、声音提醒和拿给对方看的文字入口，校园办事放在沟通之后。
- 首页直接显示麦克风、摄像头与 Watch 当前状态。打开字幕或声音页面不会自动启动采集，仍需主动点击开始。
- 沟通页突出最近两段文字和三个快捷回应，较早文字折叠。写回应入口直达输入区；切换分区回到顶部，成功显示回应后退出固定画面，避免新回应被旧阅读快照遮住。
- 提醒页把“我已看到”、人工复核与 Watch 接收状态分开；连接可达不代表手表已收到。可以直接确认已看到，误报仍到详情复核。
- 办事页增加沟通之后的材料、旅程和重要信息核对入口；“我的”提前放置阅读、提醒与沟通卡偏好。模型、API、保存格式和 Watch 协议沿用原实现。

具体入口见 [0.52 使用说明](docs/hearing-v052/使用说明.txt)，本轮实际检查范围与保留的初轮失败见 [0.52 验证记录](docs/hearing-v052/验证记录.txt)。截图位于 `docs/hearing-v052/screenshots/`。

## 0.30 新增：校园办事旅程与本机模型

- 一段旅程集中问题、材料版本、沟通摘录、确认卡、关联事务与办理结果，支持暂停和继续。确认卡区分“我已核对”与“用户记录对方已确认”，修改或来源变更后重新核对。
- 原文行号、版本和保留原图之间可定位；补充通知标出直接受影响的项目。一份通知可以预览、修改标题/日期并选择拆成多件事务，整批通过后一起保存。
- 随身办事单显示安排、材料、未解决问题及关联变更。办理结果可以建立后续事务，提醒由用户主动开启。事务变化会使直接受影响的旅程确认失效。
- 旅程可导出加密接力文件，导入前查看版本和冲突；维持手动文件接力。Watch 摘要提供版本失效通知，查看回执只对应当时版本，断连不当作成功。
- 自愿开启的事务编辑恢复提供重启后预览与版本冲突保护；列表偏好保留。文字分享增加隐私隐藏与最终预览。
- 内置 Whisper Base 多语言模型和分词器，支持最多5分钟本地文件、时间分段及复核提示。Tiny / Small 可主动下载。为兼容运行库，对 Base 的 Core ML 输入输出做了适配，未重新训练权重；因此安装包增加约145MB。
- 新增 PANNs Cnn10（527类）本机声音分析，与 YAMNet 用同批公开录音对照；也能主动选择短声音文件。PANNs 不自动替换实时提醒引擎。OCR 增加小字分区、对比度复核、候选行与低置信度提示。
- 修正原图对照返回时旧识字结果重复投递覆盖编辑的问题；每次新导入带独立回执，重复读取相同文字也能区分。编辑区保留原生光标与输入法组合状态，避免连续输入被拆到两处。
- 246项逻辑检查、17项服务检查通过；11条iPhone、7条iPad标准流程经修复复查通过，另走通1条配对Watch摘要传递及旧版失效流程。Debug与Release构建通过；Watch模拟器重启恢复连接的情况、模型验证范围和真机待验项均单独记录。

操作入口见 [0.30 使用说明](docs/campus-v030/使用说明.txt)，真实检查范围见 [0.30 验证记录](docs/campus-v030/验证记录.txt)。模型来源、固定版本与转换记录保存在 `References/PANNs/` 和 `References/WhisperKitBase/`。SNN 仍是历史归档，没有恢复到应用；未接入 PaddleOCR、自动云同步或远程联系人协作。

## 0.20 新增：专注处理与清单效率

- 底部新增事务入口，首页直接显示进行中事务的下一步；没有普通事项时提供整理材料入口，演示内容不计入真实数量。

## 运行手机与手表

1. 打开工程，选择 `SeeSound`，在配对的 iPhone 模拟器运行。
2. 选择 `SeeSoundWatch`，在对应的 Watch 模拟器运行；如果手表未出现应用，先确认两端安装完成。
3. 手机进入「现在 → 腕上回应」，点击「激活 / 检查通信」；手表点击「连接手机」。
4. 两端可达后，手机点击「发送通信测试卡」，手表会显示明确标注的演示卡。

6. 关闭一端 App 后，另一端会提示不可达。再次打开并激活后可重新发送；不会补传断线期间未发送的事件。

## 四条链路

### 声音关注

默认采用 Apple 的实时声音分类样例，也可主动选择 YAMNet Core ML 本机实验引擎。切换引擎会停止采集，需手动重新开启。对开启的声音类别使用可调阈值与连续窗口证据；默认首位得分至少为 0.65，连续两个窗口成立才形成候选事件。中断证据、时间倒退和过长输入间隔会重置规则，同义标签归为同一事件类别。

此阈值尚未经过真人场景校准。得分不是正确概率，合并次数也不是实际敲门次数。模拟器页面不会伪造分类得分，真实识别需要麦克风真机验证。

### 手部检测

参考 Apple Vision 示例提取关键点，增加一个手掌横向反复运动的规则原型。它不是训练好的挥手模型，不能判断动作是否针对用户，更不能代替用户确认事件。当前请先以竖屏测试。

没有清晰关键点时停止判断。停止或切到后台后会取消本轮采集；不记录视频或识别人脸身份。

### 面对面沟通

使用系统 Speech，先检查中文端侧识别能力，再设置必须在设备上识别。不支持、不可用或权限被拒时停止，不静默回退到云端。支持文字输入、系统朗读、自定义快捷沟通卡、大字展示和清空。手机用阅读 / 回应两个区域切换；iPad 普通字号横屏时左右分栏。顶部采集和暂停阅读控件常驻，输入状态与连续字幕等选项折叠在阅读页。

朗读前暂停麦克风分析，避免自己的声音触发识别；朗读结束不会自动恢复采集。字幕按段识别，默认手动继续，可选前台自动连续分段；每次最多 20 分钟 / 60 段，遇到权限拒绝、不可用、中断或后台时结束，不提供无限时连续识别。

在「面对面沟通」中点击卡片只填入输入框；「显示回应」将文字加入本次会话，「朗读并显示」同时请求系统朗读。右上角菜单可进入面对面阅读、停止或清空。暂停阅读只固定屏幕，不停止已开启的采集或共享。可手动标记说话者，快捷纠正只在编辑页点击后应用，不自动改写新字幕。对话不加入事件摘要导出；单独保存需要逐次确认。姓名、数字和地点需要双方确认，原始识别内容及人工修改都不能自动当作可靠标签用于训练。

### iPhone / iPad 文字共享

发送端选择“发送这台设备的对话”；接收端发现房间、输入发送端屏幕上的连接码，发送端再核对设备名并允许。每次只连一台，使用随机的设备类型标签，不广播用户设备名称。连接码只用于选择房间，不能认证真实身份；双方应当面核对。

共享不传音视频或文件，不在接收端落盘。接收端可暂停阅读旧版本，确认只指向当时看到的版本；旧确认不能代表新文字已读。进入后台、停止、连接失败或信号超时后清除接收文字及暂停副本。切换声音场景只停止采集；全局“停止采集与共享”同时结束连接。

### iPhone / Watch

参考 MIT 许可的 Watch-Connectivity-Sample，新增版本化消息结构、大小限制、5 分钟有效期、重复事件处理、接收回执和用户确认区分。

可以发送明确标注的通信测试卡，也可从事件详情手动转发未过期的待确认事件，不自动共享检测结果。两端可达时才发送，不可达时不排队；未实现后台通知、远程联系人或 iPad 到 Watch 的中继。Watch 触觉仅在 App 活跃时尝试，不能承诺后台实时振动。手机与手表的确认均会通知对端，失败时保留手动重试入口，不把本地确认自动当作对端同步成功。新增快捷回应仍受最近 5 分钟、已知待确认事件与可达限制，手机显示回应文字，不因此确认事件。

## 数据与隐私

默认不采集；麦克风和摄像头在用户主动点击后才请求权限。场景演示的事件使用独立内存账本，不写入事件历史；演示对话和原对话也分开，结束时撤销演示并恢复原内容。普通事件历史默认关闭，最多 40 条事件只保留在内存；自愿开启后，摘要、复核与备注写入应用专属目录的 SQLite 数据库。偏好和常用语仍单独保存为 JSON。旧事件 JSON 经过校验、事务迁移及读取验证后才删除；迁移出错时保留原文件。声音关注、字幕和手部检测不保存原始媒体；临时对话默认不持久化，只有在保存页单独确认才写入 SeeSoundConversations 目录；最多 30 份，单份最多 50 段。保存会话与事件历史、常用语是独立数据，删除事件或清空临时对话不删除已确认保存的会话。没有应用账户或云端同步；可选的 DeepSeek 整理仅在用户明确发送时把选中文字交给配置的服务，随后由服务请求 DeepSeek，不上传录音或画面。

个人声音样本是单独的主动采集入口：录制 / 导入后临时存放供试听，确认才保存特征及人工标签，原音频默认不长期保留。用户打开“同时保留原音频”后，该段音频也保存在专属 Library 目录；删除样本时一起移除。特征导出排除原音频和备注，但仍由用户决定分享对象。未确认临时音频在停止、离页时移除；意外退出遗留的专用临时文件在下一次启动时清理。

本地目录排除系统备份，文件限制为当前用户读写，iOS 上启用系统文件保护。关闭历史会关闭数据库并删除数据库、辅助文件和旧事件 JSON，保留当前内存事件；「删除全部事件与备注」同时清空内存与持久化内容。用户导出的副本需单独删除。读取格式损坏时保留原文件、提示错误并暂停写入，可删除全部记录后重置；保存或删除失败会明确提示，不能将开关状态当作磁盘操作成功的证据。

WhisperKit 模型准备访问 Hugging Face；文件转写在本机执行，不上传音频。公开声音录音和 YAMNet 模型已随包提供，不需要这个下载步骤，也不加入私人样本库。释放转写引擎内存不删除磁盘模型。卡片分享码包含原文，不是可信身份凭据，请只分享适合对方看到的文字。

切出前台时停止音视频采集与朗读，不自动恢复。没有申请后台摄像、后台音频、定位或联系人权限。系统通知仅在提醒设置中主动点击授权按钮才申请，默认不发通知；补提醒只针对此前已产生的事件，不代表后台识别。启动 App 时取消上次运行的待发通知，不自动重新排队。
