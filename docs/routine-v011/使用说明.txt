见声 SeeSound 0.11 · 从沟通到处理约定
日期：2026-10-27（北京时间）

本轮新增七组功能
1. 今日工作台：首页“今天先做什么”或“我的 → 日常工具 → 今日工作台”。把待看提醒、待核对卡、待完成事项放在一起，点数量可打开相应页面。
2. 约定与待办：工作台“全部待办”，或首页常用工具 / 我的日常工具。支持手动建立、普通 / 重要优先级、约定时间、备注、搜索、筛选、完成与重新打开。
3. 核对卡转待办：信息卡详情中先标记“我已与对方核对”，再点“从已核对卡建立待办”。只在用户完成编辑后建立，不会自动保存或完成。时间卡带入日期时间，其他卡可自行设定。
4. 信息卡整理：列表可搜索内容、原文或备注，按类型和状态组合筛选；详情可置顶。置顶不改变核对状态、内容版本或是否保存。
5. 场景模板：我的场景内有宿舍、图书馆、服务窗口、出行。点模板先预览编辑，保存后再点应用；不会直接开启采集、系统通知或触感。
6. 时间线整理：联合时间线可搜索事件名称和人工备注，并按全部、近 24 小时、近 7 天筛选。保留此前的声音 / 动作 / 演示分类及拆分操作。
7. 三套新演示：场景演示内新增约好一件事、窗口办事、出行问路。各有两张预设信息卡，点击准备后仍需用户核对，随后才能建立待办。它们不是识别或自动抽取结果。

待办的来源和处理
从核对卡建立时保留版本和摘录。原卡若后来改变、取消核对或当前不可用，列表和详情会提示。
“按最新已核对卡重建约定”会重新生成标题、摘录和约定时间，保留备注，并重新设为待完成；需要最新卡本身已有核对标记。
如果用户决定按保留的摘录完成，可在提示中明确确认；这不会修改原卡。完成待办也不会确认声音事件。
同一个来源版本已有未完成待办时，会拒绝重复建立；可以先处理已有记录。
到期提示只在打开见声时显示，不安排系统通知。列表中的到期状态每 30 秒更新。

本地保存
待办默认只在本次运行，逐项勾选“将这项待办保存在本机”才保存，最多 80 项。
取消勾选并完成编辑会删除已存副本，内存中的待办继续可见。
待办、信息卡、事件历史和保存会话各自独立；保存待办不等于保存来源卡。来源卡未保存或已删除时，待办仍保留摘录并提示原卡不可用。
损坏文件会保留并阻止覆盖；页面提供明确删除本地待办并重置的入口。
切换或结束场景演示时清理未保存的演示卡及待办；主动保存的演示内容保留演示标记。
工作台只把非演示数据计入实际数量；演示待办可在待办列表中单独选择是否包含。

实际检查和限制
84 个 XCTest 用例通过；Debug iOS 模拟器和 Release 通用 iOS 编译通过，包含 Watch，版本 0.11 / build 11，最低 iOS 17.3 / watchOS 9.6。
本轮实际打开工作台、启动约定演示、准备信息卡、标记核对并进入待办编辑器，看到时间、演示来源及版本摘录已带入，保存默认关闭。
之后电脑操作连接中断并重新连接超时，待办保存 / 完成 / 重启和后续 UI 操作尚未完成。自动测试覆盖对应数据服务，但不替代界面检查。
本轮没有真实录音、录像、重新训练 SNN 或更改模型参数，也没有上传 GitHub。
新页面的完整 iPad / VoiceOver / 大字号交互、真实通知和触感不属于本轮已通过范围。
