见声 SeeSound 0.30 · 校园办事版

开始体验
打开工程运行后，在“现在”顶部点“开始或继续办事旅程”，进入“校园办事”。
点“体验补办学生证示例”，可以不用麦克风、摄像头或 API 体验完整流程。
示例中的校园规定是模拟内容，不代表学校实际要求。

1. 一次办事放在一段旅程里
可以新建旅程，留下问题、加入材料、保存沟通摘录、关联事务。
阶段包括准备、沟通、核对、出发、跟进、结束；可以暂停后继续。
旅程文字主动保存到本机，不保存录音，也不自动共享给家人。
现场字幕仍在“面对面沟通”中使用；需要留下文字时，主动保存会话，再复制所选会话或摘录到旅程。

2. 大字确认卡
时间、地点、费用、材料和其他约定分别建立卡片，每项都需要原文依据。
先点“我已核对这项信息”，再把卡片给对方看。当面询问后，才能记录对方确认。
“用户记录对方已确认”是本人的记录，不是对方的远程签名。
修改内容、换用新版本依据，或关联事务改变了直接引用的安排后，旧确认会失效。
没有实际改变内容而保存，不会清除原有确认。

3. 从结论回到依据
确认卡可以打开“回到原文与图片位置”，查看加入时版本、原文行号和摘录。
材料保留了原图时，还可以定位对应识字行；没有保留原图或在另一台设备上时，保留文字核对入口。
事务清单中展开“建立时依据”，也能打开单独的原文核对窗口。
更新事务时，直接引用旧时间、地点或费用的清单项目会单独提示；其他依赖仍需人工复核。

4. 一份通知拆成多件事务
先到文字工作室打开一份通知，在独立事项之间保留空行。
打开“从一份通知拆分事务”，生成预览后选择需要的事项。
可以修改各自标题，核对或关闭候选截止时间，再确认保存。
不会推断相对日期，不会自动开启提醒。原文、版本和各项依据一同保留。
整批通过检查后一起保存；原文已变更、重复建立或有一项无效时会拒绝本次建立。

5. 出发和办理后
“随身办事单”汇总已核对安排、未解决问题、材料和剩余步骤。
关联事务改变安排或材料后，会提示重新对照；简单勾选进度不会要求重核全部安排。
“我已对照最新关联事务”只更新已查看的版本，不会重新确认失效的信息卡。
办理后记录结果，可建立一件后续事务。只有主动开启后续提醒，才安排通知；是否能通知取决于系统授权。
结束旅程不会擅自完成关联事务。

6. iPhone / iPad / Watch
旅程详情中可以导出只包含这段旅程及关联已存资料的加密接力文件。
在另一台设备的“备份与恢复”选择文件，输入密码后预览版本、冲突、缺失关联和提醒选项。
默认保留本机同标识版本、不重新开启提醒；需要覆盖时要自己明确选择。
原图、API 密钥、系统权限、模型文件和未保存的编辑恢复副本不进入接力文件。
这是手动文件接力，没有自动云同步。
Watch 的旧摘要在安排变化后会失效；查看回执只对应当时的记录版本。
断连时不会把操作标成成功，仍需取得手机回执。真实设备的连接、触觉和通知需要另行验证。

7. 恢复、偏好和分享
“恢复编辑与隐私”可主动开启事务编辑恢复，默认关闭。
有效修改会留下本机恢复副本；重启后先预览，由你选择恢复，原记录有更新时拒绝覆盖。
关闭该功能会删除恢复副本。文字工作室另有原有的草稿保护开关。
事务的排序、附加筛选、查看状态和是否包含演示资料会保存；搜索词不保存。
事务、材料、会话、核对卡和待办的文字分享经过预览，可以隐藏手机号、邮箱、身份证号，并逐行指定姓名、学号等内容。
自动识别不能覆盖所有隐私，请检查分享预览。

8. 页面和操作
首页优先放办事旅程、继续处理和重要提醒，声音及其他工具放在后面。
大字卡、材料核对和办事单沿用统一的色彩与按钮样式。
iPad 保留原有分栏事务和原图对照；窄屏与大字号采用单列布局。
键盘可以收起，主要操作保留可读标签；无障碍实用性仍应由真实用户进一步反馈。

文件转写
Base 均衡模型和分词器已内置，进入“文件转写”后点“准备内置 Base 模型”。
Tiny、Small 可主动联网准备；除 Base 外的设备表现仍需另行验证。
支持最多5分钟、100MB的本地音频。结果最多12000字，提供时间分段和需重点复核的片段提示。
音频在本机处理，不上传。文件转写与实时字幕是两个入口，不会代替系统权限或自动加入沟通。
可以核对后主动加入本次沟通，或先隐藏隐私再分享。
模型可能听错姓名、数字和方言；内置模型使安装包增加约145MB。

环境声音
“环境声音实验”可选 YAMNet 轻量基线或 PANNs Cnn10（527类）。
可以使用随包公开录音，也可以主动选择0.1–10秒、25MB以内的本地声音文件。
两种模型在本机运行；文件不自动加入个人样本库，不产生正式提醒。
批量检查对前六段公开录音分别运行两种模型与两档幅度，只显示本次实际输出。
正式声音关注保留现有轻量引擎；PANNs 五秒分析窗口不自动替代实时提醒。
模型得分不等于正确概率，公开样本结果不能当成居家准确率或省电结论。

图片识字
在原有 Vision 准确识字上加入小字分区复核、必要时的对比度复核、候选文字与低置信度提示。
原图保留开关仍由你选择；增强处理不上传图片。
识字行可以回到原图位置。多栏、表格、手写文字和模糊数字仍需人工检查。
本版没有接入或宣称安装 PaddleOCR，也没有恢复 SNN。
