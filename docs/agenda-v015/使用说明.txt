见声 SeeSound 0.15 · 事务与到点提醒

这一版完善从文字材料到实际处理的日常流程。
最低 iOS 17.3 / watchOS 9.6，不需要升级用户设备系统。

一、首页与导航
底部新增“事务”，不用再从更多工具中寻找。
首页最上方显示进行中的非演示事务及下一步，最多显示两件事务和一项待办。
没有普通事务时显示整理材料的入口；演示内容不计入真实事务数量。
点击搜索按钮，可按事件、已存会话、信息卡、待办、草稿和事务筛选本机搜索结果。
搜索不联网，不读取其他 App；没有新增 API 使用记录页面。

二、事务清单
支持进行中、今天到期、已到期、已完成、已归档和全部视图。
搜索覆盖名称、备注、材料、步骤与关联摘录。
排序依次考虑置顶、到期、重要程度、截止时间；上方数字只统计非演示事务。
向右滑可置顶或取消置顶，向左滑可归档或恢复，归档不删除记录。
事务卡片显示进度环、下一步和截止时间；演示事务始终保留演示标记。
事务上限由 20 件调整为 100 件，归档事务也计入上限；存储文件仍有容量校验。

三、编辑安排与完成
进入详情 → 编辑事务与提醒，可修改名称、备注、重要程度、置顶和截止时间。
截止时间由用户设置，不从模型或原文自动启用提醒；不把它说成通知里已经确认的事实。
“下一步”优先显示未准备的材料，再显示未处理的步骤，最后显示关联待办。
所有材料、步骤和关联待办处理后，才可标记事务完成；没有任何事项的事务不能直接标记完成。
完成不等于信息卡已核对，不会自动报名、缴费、发消息或改变原事件。
完成后清单不可直接改动；重新打开可继续编辑。归档后先恢复，再继续处理。
关联待办后来重新打开时，已完成事务显示未处理项提示，由用户重新打开事务。
归档和恢复保留原有进度及来源。默认仅本次运行，主动保存后才写入本机。

四、手动设置系统提醒
事务和待办的编辑页均提供“到点提醒我”。约定/截止时间与提醒时间分别设置。
打开开关只编辑草稿，不发送通知，不自动申请权限；保存后才进入提醒安排。
提醒需要将事项保存到本机；勾选提醒时会同时勾选保存，取消提醒后才可取消保存。
点击“允许系统通知”才向系统请求授权。系统已拒绝时需到系统设置中开启，再回应用刷新。
演示内容不安排系统通知。已完成、已归档的事项也不安排。
通知显示通用“见声 · 事务提醒”或“见声 · 待办提醒”，正文不包含名称、原文、地点或金额。
通知点击处理代码会按事项标识打开对应详情；已删除的事项显示已移除，不会重建记录。
修改提醒时间会替换旧请求；关闭提醒、取消保存、完成、归档、删除或重置会撤下未触发的提醒。
同一事项保留一个提醒，不重复安排；已经过去的时间不在重启后重新推送。
重新打开或从归档恢复，若原来手动设置的提醒仍在未来，会重新安排；需要时可先改提醒时间。
从最新信息卡重建待办会清除旧提醒时间，需要重新手动设置，以免按过期约定提醒。

系统限制：最多预排最近 24 条事务/待办提醒，超过的部分在下一次打开应用或修改事项时补排。
事件提醒同时最多跟踪 10 个事件，每个最多 3 次请求，为系统待处理数量留出余量。
专注模式、通知设置和系统状态可能影响显示时间，不提供闹钟级保证。
页面区分“设置了提醒时间”和“已排入系统通知”；未排入时显示原因或状态。

五、演示路径
1. 文字工作室 → 读书会演示材料 → 核对 → 离线整理 → 预览事务 → 确认建立。
2. 底部“事务” → 打开演示事务 → 编辑 → 设置重要、置顶及截止时间。演示不启用系统提醒。
3. 勾选材料和步骤，观察进度与下一步变化；全部处理后标记完成。
4. 归档 → 切换已归档 → 恢复 → 重新打开，原进度仍保留。
5. 如需体验普通事项的设置页，新建事务 → 到点提醒我 → 查看时间和授权状态。取消编辑不会建立事务或安排通知。
6. 真正测试送达时，需要自己建立并保存普通事项、明确授权、设置将来的提醒时间，然后检查前台、后台及点击通知。此项硬件送达尚未验收。

六、验证范围
本轮自动检查结果和最终构建结果记录在项目根目录“验证记录.txt”。
专项检查覆盖旧资料兼容、日期校验、搜索筛选、完成门槛、归档进度、显式保存、演示隔离、提醒去重、改期、权限关闭、数量上限、失败重试、异步旧请求清理及前台通知抑制规则。
提醒协调器通过可替换的通知接口检查，测试使用内存替身，不冒充真实系统送达。
iPad 模拟器实际走通编辑、勾选、完成、归档、恢复和重新打开；普通提醒开关确认不会自动请求权限，随后取消未保存的编辑。
iPhone 与 iPad 已安装新版。截图是实际模拟器页面：iPhone-Home.png、iPad-Cases.png、iPad-ReminderSettings.png、iPad-CaseDetail.png。
提醒设置截图为未保存的编辑状态，没有发出通知或新增普通事务；演示事务不保存到本机。
本轮不调用付费 API，不新增第三方依赖，不做真机安装、不验证锁屏送达、通知点击恢复、实际 Watch 触觉或识别准确率。
