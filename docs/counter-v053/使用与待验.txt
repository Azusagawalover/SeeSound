入口
沟通首页 → 沟通之后 · 校园办事 → 体验补办学生证示例 → 窗口办事 · 按四步继续。
已有未结束旅程时，“沟通”首页与“办事”页的“继续窗口办理”可直达同一段旅程。
创建自己的旅程：校园办事 → 按场景开始 → 窗口咨询或补办证件；检查问题并明确保存后，打开四步入口。

不用真实录音的体验路线（下列时间、地点和材料均为模拟示例）
1. 准备
查看模拟材料与提问清单，可补充一个问题“领取时需要带什么？”。点击“加入提问清单”才会保存新增问题。
2. 交流
点击“大字说明，拿给对方看”，了解应用会怎样说明听障沟通需求，再结束展示返回。
点击“大字提问”展示当前问题。关闭后通过“请对方输入 / 我来记回答”填写一条模拟回答，例如“请到学生服务中心一楼提交材料。”，保存后当前题显示这条回答。
“下一个问题”只换题，不会自动记录或确认回答。若想体验字幕入口，可以只打开页面再返回，不点击“开始字幕”。真实收音留待之后检验。
3. 核对
进入“核对”，找到已记录的回答，点击“从这条回答建立待核对卡”。类别选“地点”，内容选取回答里的“学生服务中心一楼”。检查依据、主动同意，再建立。
回到列表打开新卡，先操作“我已核对这项信息”，再按实际情况记录对方确认。演示流程中的对方确认同样只是用户操作记录。
4. 结果
进入“结果”，查看哪些问题还没回答、哪些当前安排已核对。点击底部“记录本次办理结果”，选择“需要补材料”起句，补充具体情况。
如需后续事项，可手动填写“带齐照片后再次到窗口”；提醒默认关闭，演示旅程不安排通知。保存后查看最近一次记录和后续事项入口。勾选结束旅程才会结束，否则保留待跟进。

接着可检查的边界
修改回答：回“交流”改掉已用于建卡的回答，再到“核对”查看旧卡失效、旧确认清除。旧依据仍可展开对照；重新建卡采用当前回答，仍是待核对状态。
取消输入：在回答页或结果页输入文字后点击取消，应该先询问是否放弃；继续编辑应保留刚才输入。下拉也不应直接丢弃修改。
重复建卡：用同一回答、类别和原句再次建卡，应该复用既有卡片。
保持位置：打开字幕后返回窗口页，应保留当前题；切换步骤后，回到该步骤顶部。切换步骤不会改变确认或办理结果。
字体和界面：放大系统字体后，步骤入口改为两列；查看手机竖屏、iPad 和深色外观的文字、滚动及按钮。

来源与保存
手动回答保存到原旅程。建立核对卡前会再次预览并征得同意，将当时的回答作为有版本的材料快照保存；它不是逐字录音，也不是学校发布的通知。
在窗口页看到的当前会话文字，可能来自更早的交流。需核对是否属于这次办理，只有主动记录或选取摘录才加入旅程。没有自动录音、自动提交、自动确认或自动开启通知。
旧旅程与已有字段继续使用原保存格式。本轮没有添加模型或付费 API 调用。

本轮未做的现场验证
没有把上述手动路线标为已通过。页面点击、字幕效果、实际声音、Watch 触觉／回执、后台行为和目标用户体验留待用户后续验证。
