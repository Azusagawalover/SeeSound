见声 SeeSound 0.9 使用说明
更新日期：2026-10-27

本版入口
首页右上角「常用工具 → 场景演示」，或「我的 → 日常工具 → 场景演示」。不需要麦克风即可开始。

一、有人来访
点击「开始有人来访演示」，两条预设门铃 / 敲门事件进入应用内队列。新事件不会覆盖你正在看的卡片；下一条和收起不确认事件。点全部可逐条查看、确认、暂缓或恢复，并手动转发到配对 Watch。醒目提醒在选择下一条时优先，不打断当前卡片。
演示事件保存在独立内存账本，不写入事件历史。演示暂缓只作用于演示类别，不暂停真实提醒；正式提醒仍按各类规则进入队列。队列最多 48 条，真实事件账本仍最多 40 条。暂缓五分钟后，仍存在的待处理卡片恢复；通知不会因此自动重新排队。
点「打开专注沟通」进入阅读页，再切到回应，修改预填示例或选择沟通卡。点击「显示回应」才将内容加入会话，点击「朗读并显示」会实际播放朗读；不会自动开启麦克风。
两端打开且已配对时，手动激活 / 检查通信，再转发演示事件。Watch 的“请等一下 / 我马上来”是回应，手机收到后仍保持待确认；只有主动点“我已看到”才确认。五分钟以上的事件不再转发，断线不排队。

二、面对面交流
点击「开始面对面交流演示」，加载带说话者标签的两段预设文字，并准备一句回应草稿。
手机分为阅读 / 回应两个区域；上方保留采集状态和暂停阅读。阅读页最新内容在上方，字幕选项与输入状态折叠。回应显示后返回阅读，所有演示回应都保留演示来源。
iPad 横屏、宽度足够且未使用辅助功能大字号时，左侧阅读、右侧回应，两边分别滚动。竖屏、小窗口或辅助功能大字号时使用单栏。无需旋转整个中文界面或改变阅读方向。

三、把手机文字放到 iPad
进入「连接 iPad 文字屏」。手机点发送对话；iPad 点接收文字、选择房间、输入手机屏幕上的六位连接码。手机再次核对设备名并允许。连接码选择房间，不认证真实身份，双方应当面核对。
只传最近 20 段文字及来源 / 标签，使用系统加密连接，不传音视频、不在接收端落盘。未主动确认时，手机只显示设备连接，不显示已读。
iPad 可暂停阅读，固定当时的版本，同时继续接收新文字。此时点“我已看到这版文字”只确认固定版本；手机后续新内容仍显示未确认。回到最新后再确认，手机才显示当前版本已读。连接信号不制造新文字版本，也不算已读。
进入后台、主动结束、连接断开会清除接收文字和固定副本；外部截图、复制和主动导出的文件需要另行管理。连续无信号的保护仍按 45 秒阈值、下一次检查执行；本轮没有模拟全部真实网络丢包组合。

四、结束演示
顶部「结束」或页面「结束并恢复」会停止演示共享、移除演示队列和事件，恢复开始前的对话与输入草稿，麦克风保持关闭。切换演示场景不会用前一个演示覆盖原对话。
预设演示与手动回应均为临时内容；只有在保存会话页逐次确认才写入本地。原有事件历史、常用语和已保存会话不因结束演示而删除。
Watch 只接收事件摘要，演示结束不代表可以远程抹除 Watch 已经显示过的卡片；发送新事件可更新其显示。没有伪造确认去清除对端记录。

五、本轮已实际操作的范围
1. iPhone 15 / iOS 17.5 与 Watch Series 7 45mm / watchOS 10.5 模拟器真实 WatchConnectivity 消息交换：演示门铃送达，手表回传“我马上来”，显示手机已接收但事件尚未确认；再从 Watch 主动确认，手机标为已在手表确认，队列从两条减为一条。
2. 手机切换下一条时两条都仍待确认。暂缓剩下的敲门后，队列显示一条暂缓；在队列恢复后重新显示待处理，最后手机确认清空演示队列。
3. 手机实际切换阅读 / 回应，预填示例只在回应框中；主动显示后回到阅读，段数从两段变三段，新增回应标为演示。
4. iPad 实际收到两段演示、暂停阅读后仍保留旧画面；手机新增回应后显示收到第二次更新，但没有将第三段挤进固定画面。确认固定旧版后，手机显示“对方确认了较早版本；最新文字尚未确认”；回到最新看到第三段并再次确认后，手机显示当前版本已主动确认。
5. 发送端进程在更新代码时结束，iPad 显示断开，固定文字清除；手动连接新房间成功。接收端再次固定画面、进入主屏幕再回到应用后，显示共享已结束，接收文字和固定副本没有恢复。
6. iPad 第十代 / iPadOS 17.5 模拟器实际旋转横屏，左右同时显示对话和回应 / 沟通卡，未申请麦克风。导航状态条与标题的重叠问题已修正；最终版状态条“步骤 / 查看”已实际从嵌套页面正确跳转。
7. 57 个 Swift XCTest 用例通过，含本轮 11 个新增用例；新增用例检查队列、暂缓与真实 / 演示隔离、演示备份切换恢复与旧采集回调失效、版本已读和 Watch 消息。不是识别准确率或真实设备试验。
8. Debug iOS 模拟器及 Release generic iOS 构建均成功，含嵌入 Watch。版本 0.9、build 9，最低 iOS 17.3 / watchOS 9.6，关闭签名。没有实际安装到用户 iOS 17.3.1 / watchOS 9.6.4 设备，没有测量真实字幕效果、触觉或能耗。
9. 大字号、完整 VoiceOver、窄窗口和全部系统通知呈现组合仍待进一步操作验收；公开 SNN 数据、模型、Python 训练部分未改，本轮未重跑其 Python 检查。
