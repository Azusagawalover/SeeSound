## 获取与固定

当前工具为 Xcode 15.4 / Swift 5.10。新版本库可能要求更高的 Swift 版本，因此本轮固定到已检查的兼容版本。
远程 Git 拉取停滞后，改为官方 GitHub codeload 固定标签源码包；原归档的下载 URL、版本、SHA-256 位于 `Vendor/SOURCE_MANIFEST.json`。
工程使用本地 Swift Package 引用，打开工程不需要重新从 GitHub 获取这九个运行包。
源代码、上游许可、嵌入库声明及经过修改的原始包清单位于 Vendor 和 Resources，具体改动见 `Vendor/PATCHES.md`。

0.10 的 SwiftUI-Flow 3.1.1 源码与包清单未修改，原 MIT 许可同时保留在 Vendor 和应用内完整声明中。其最低 iOS 16、Swift tools 5.9，已在本工程 Xcode 15.4 / Swift 5.10 下构建；没有将它链接到 Watch。自定场景继续使用既有偏好存储；核对卡及关联规则由本工程实现，没有借用完整第三方应用界面或宣称第三方模型性能。

## 数据迁移

- 用户未开启历史保存时不创建事件数据库；偏好和常用语仍单独保存在 preferences.json。
- 开启历史后使用 events.sqlite。首次读取旧 events.json 时先校验、事务写入，再读取校验新快照；成功后才删除旧 JSON。
- 原文件损坏时保留原文件并报告错误，数据库不会接受无效快照覆盖已有内容。
- 关闭历史时关闭数据库连接，再删除数据库、相关辅助文件和旧 JSON。应用当前内存中的事件仍可查看。
- 到期过滤、40 条上限、演示来源、确认状态和人工复核保持原语义；没有把字幕写进事件库。

## 分享码

分享格式为 SeeSoundCards / version 1。每码最多 8 句、4096 字节，每句不超过 80 字。
扫码与手动粘贴使用同一验证入口，拒绝不支持格式、网址、空内容和重复项。读取内容后先预览，再由用户导入；已有收藏跳过，超过 48 句上限的不导入。
分享码直接包含文字，不是安全配对、签名或可信身份凭据。原始文字可供用户主动复制，不自动写入系统剪贴板。
模拟器不伪造相机扫码结果，可使用粘贴流程验证数据和预览；真实扫码需要摄像头真机检查。

## 波形与动画

波形只来自用户开启麦克风后的实际缓冲，约每秒更新 10 次，最多保留 90 个相对幅度值。
没有输入时保持空波形，不填充模拟识别结果；它不是校准的分贝计。
ListeningPulse.json 是本项目制作的矢量动画，Lottie 负责播放。动效预览明确标注为预览，不开启采集；减少动态效果设置下保持静态。

## 文件转写

- 首次模型准备是单独的用户动作，会访问 Hugging Face 下载 openai_whisper-tiny 多语言模型及分词器；没有把模型权重打进项目。
- 用户可选择中文、英语或自动检测语言。当前输入限制 60 秒、25 MB，最多显示 2000 字，加入本次会话时明确限制为 500 字。
- 可用系统文件选择器选取音频，也可通过 Finder 文件共享放入见声的 Documents；该目录在“文件”App 可见。事件、偏好和模型缓存位于 Library，不通过这个入口公开。
- 转写仅使用选定的本地文件，不上传音频。结果先供核对，点击加入后才进入内存会话，并标注 WhisperKit 文件转写来源。
- 本地准备路径禁止分词器回退下载。缺失或损坏时提示使用明确的联网修复入口。
- 退出页面或切出前台会停止等待；部分已下载缓存可能保留。释放引擎内存不等同于删除磁盘缓存。
- 引擎接入、编译通过与真实转写准确率是不同的验证范围，实际模型下载、载入和推理以验证记录为准。

### 本机准备记录（2026-10-26）

按用户指示，已在本机 iPhone 15 / iOS 17.5 模拟器的 App 中下载 tiny 多语言模型及分词器，缓存约 78 MB，页面实际显示“引擎已就绪”。重新安装应用后选择“从本地缓存准备”，也成功恢复引擎。缓存属于该模拟器的数据目录，未加入源码；安装到其他模拟器或真机时需要单独准备。

另在 Mac 上用同一份模型及固定版本 WhisperKit，在禁止下载的配置下完成一次真实推理。Tingting 合成语音输入“你好，请用文字告诉我。我正在看字幕，谢谢。”，输出“你好,請用文字告訴我,我正在看字幕,謝謝”。音频位于 `open-source-v05/synthetic-zh.aiff`。这是一条合成样本的链路检查，不是准确率实验，也不是 iPhone 性能测试；App 内系统文件选择器的完整操作流程尚待验证。

## 0.30 模型与适配

- Whisper Base：OpenAI 预训练多语言权重，Argmax Core ML 转换，MIT。固定下载文件及 SHA-256 在 `References/WhisperKitBase/download-manifest.json`。本工程增加 float32 输入输出边界、分词器打包和运行库适配，不宣称自行训练。
- PANNs Cnn10：Qiuqiang Kong 等，代码 MIT；Zenodo 3987831 预训练权重 CC BY 4.0。原始文件 MD5、SHA-256 与转换说明在 `References/PANNs/model-source.json`。本工程拆出 Swift 前处理，转换为 Core ML，提供独立声音分析与对照。
- YAMNet：保留原始 Google / Yehor 来源，增加 float32 接口以适配运行库。Swift 前处理与原始 TensorFlow 数值检查继续保留。
- Vision OCR：系统准确识字，加上本机小字分区、必要的对比度复核、识字候选与依据定位；没有安装 PaddleOCR。
- 自行实现部分：旅程与确认状态、变更失效、证据导航、通知拆分事务、办理结果、手动接力筛选、编辑恢复、分享预览，以及各模块的连接与检查。

转换验证只证明所列样本的数值或输出接近，不等于真实环境准确率、节能结论或用户研究。
