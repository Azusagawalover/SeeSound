# 0.7 公开声音实验

默认入口：现在 → SNN 实验室。无需自己录制、开启麦克风、下载模型或联网，即可使用随 App 提供的公开录音和模型。

## 可以操作什么

- 在敲门、拍手、键盘声和吸尘器的 24 段测试录音中选择样本，播放 / 暂停，拖动时间线，逐帧前后查看；支持循环和 0.5× / 1× / 1.5× 播放。
- 同步定位原始录音的相对幅度、16 频带 Mel 频谱、32 路有符号差分脉冲与训练模型的 LIF 膜电位。
- 查看 48 个隐藏神经元中的任意一个。默认选择发放较活跃的神经元，便于观察；不按分类正确与否挑样本。
- 将训练参数与另一 β 下的单神经元轨迹叠加比较。探索不会改动已训练的模型和分类输出。
- 查看 SNN / ANN 对照、混淆矩阵、全部误判及意见不同的样本，点击回放复盘。
- 查看每段录音的原始来源、作者署名与完整许可。

分类结果使用完整 5 秒的预计算特征，明确标为“整段判断”。播放头只定位特征与神经元状态，不模拟实时麦克风分类，也不提前显示成正在发生的真实事件。
实验不写入私人声音样本库、事件记录或 Watch 消息。原有个人样本 / 数学信号 / 模型导入入口保留在页面底部。

## 数据来源和选择

数据来自 [ESC-50 官方仓库](https://github.com/karolpiczak/ESC-50)，固定提交：
`33c8ce9eb2cf0b1c2f8bcf322eb349b6be34dbb6`。

这是见声的三类子集，不是完整 ESC-50 的 50 类基准。

| 模型类别 | 原数据类别 | 数量 | 训练 / 测试 |
| --- | --- | --- | --- |
| 敲门 | door_wood_knock | 40 | 32 / 8 |
| 拍手 | clapping | 40 | 32 / 8 |
| 其他 | keyboard_typing、vacuum_cleaner | 40（各 20） | 32 / 8 |

两种目标类保留全部 40 段。其他类在每个官方 fold 内按文件名排序，固定选择 4 段键盘 + 4 段吸尘器；这个规则在训练前确定，没有按测试效果挑选。
官方第 1–4 折共 96 段用于训练，第 5 折全部 24 段用于测试并随 App 提供。原始 Freesound source ID 在训练 / 测试集合间不交叉，音频 SHA-256 去重。
“其他”只表示这里选定的两种声音；没有训练门铃，也不能把任意未知声音都当作已验证的其他类。

完整选取记录、原始 CSV 和许可在 `References/ESC50/`。模型、测试特征和 24 段原始 WAV 位于 `Resources/`。App 内显示每段录音的原始署名，保留数据集 CC BY-NC 3.0 与原始逐段许可声明。

## 特征与模型

- 原始公开录音为 44.1 kHz、单声道 PCM16、5 秒。App 播放原始字节；播放前核对音频哈希。
- 离线取 64 个等距中心帧，4096 点 Hann 窗，FFT 功率谱经过 80 Hz–8 kHz 的 16 个三角 Mel 滤波器。每段以自身最大 Mel 功率为参考，将 [-80, 0] dB 映射到 [0, 1]。
- 频谱是整段离线预计算的表示；不是校准声压，也不能据此承诺流式识别。测试会从实际 WAV 重新计算频谱，与打包数据逐项比较。
- 16 个频带各自按 0.08 步长做有符号差分，组成上升 / 下降两路，共 32 路脉冲。
- SNN：32 → 48 LIF → 3 类线性读出，64 帧时间平均。ANN：32 → 48 ReLU → 3 类线性读出，同样时间平均。两者使用相同编码，不是最强普通音频网络的性能上界。
- 训练固定随机种子 2026、80 轮、Adam、学习率 0.003、batch 16、CPU / float64。使用 snnTorch 0.9.4 / PyTorch 2.5.1，无测试集检查点选择或测试后调参。
- 模型使用 `SeeSoundExperiment` version 2 与 `esc50-logmel16-v2` 特征格式；原版 version 1 的个人样本模型继续可用，不能直接混用两种特征。

## 本次实际结果

| 方法 | 正确 / 测试总数 | 准确率 |
| --- | --- | --- |
| SNN | 18 / 24 | 75.0% |
| ANN | 17 / 24 | 70.8% |

矩阵的行为数据集标注，列为预测；顺序均为敲门、拍手、其他。

```text
SNN        ANN
7 1 0      7 1 0
0 4 4      1 3 4
0 1 7      0 1 7
```

App 会在本机重新推理全部 24 段预计算特征，复核矩阵与 Python 报告是否一致，失败时显示错误，不伪造复核成功。
该结果仅对应这一小型子集、一次官方留出划分和固定训练设置。两种方法只相差一个测试样本，不能由此得出普遍优劣结论。ESC-50 原作者还说明过原始数据可能含类别相关的预处理痕迹；不能把这个结果写成居家识别率、完整 ESC-50 成绩或低功耗证明。

完整可追溯报告在 `Training/Results/ESC50-Report.json`，含确切划分、版本、哈希、训练配置与局限。没有测量真实 iPhone 能耗、实时识别效果或公平推理延迟。
