见声 SeeSound 0.12

这一版改动
取消 SNN 实验室和对应的模型导入、神经元探索、SNN / ANN 对照，改为环境声音实验。
旧实现、参数和已发生的验证记录留作历史参考，不属于当前应用功能。
个人声音样本库继续保留，保存规则和既有导出格式不变，不会自动训练任何模型。

一、先体验环境声音模型，不用录音或配置密钥
1. Xcode 打开 SeeSound.xcodeproj，运行 SeeSound。
2. 在“现在”进入“环境声音实验”，选择一段公开录音。
3. 点击“在本机分析这段录音”，等待出现实际模型得分和分析用时。
4. 可播放、停止，换一段再分析；切换录音或离开页面会取消旧分析。
5. 这里使用 ESC-50 的 24 段公开录音，包含敲门、拍手、键盘和吸尘器。
   不使用当前麦克风，不生成正式事件，不自动发送给 Watch。
6. “我的 → 声音关注规则”可切换 Apple 系统模型与 YAMNet 实验引擎。
   切换会停止采集，真实声音关注须在真机主动开启。
   521 类得分不等于 521 类提醒；正式关注仍只使用敲门、门铃和拍手。

二、在本机私密配置 DeepSeek
不要把密钥放进聊天、项目文件、截图或 App 输入框。
在 Mac 终端运行：

cd "/Users/mac/Desktop/归档/见声SeeSound"
python3 Server/configure.py

按提示输入 API 密钥（输入不显示），并设置账户可用的模型名。
默认模型名可修改。2026-10-27 已通过官方模型列表核对并用 deepseek-flash 完成一次真实请求，详见文末记录。
配置保存在 ~/.config/seesound/deepseek.json，目录权限 700、文件权限 600。
脚本生成一个单独的 App 配对码。配对码也应保密，但它不是 DeepSeek API 密钥。
重新运行配置脚本会更新配对码，已有 App 需要重新填写。

启动服务：

python3 Server/server.py

默认仅监听本机 127.0.0.1:8765。只要使用服务，终端就需保持运行。
iPhone / iPad 模拟器：服务地址填写 http://127.0.0.1:8765，填写上述配对码并保存。
进入“沟通 → DeepSeek 智能整理 → 服务配置与检查”可设置和检查。
服务检查不发送对话，也不消耗 DeepSeek 请求额度，不证明密钥、余额或模型实际可用。

真机不能通过 127.0.0.1 访问电脑。需要你控制的、证书被设备信任的 HTTPS 服务。
当前 App 有意拒绝把文字和配对码发往普通局域网 HTTP 地址。
服务器端可使用已有 HTTPS 反向代理转发到本机 8765，或设置：

SEESOUND_HOST=0.0.0.0
SEESOUND_TLS_CERT=/绝对路径/证书.pem
SEESOUND_TLS_KEY=/绝对路径/私钥.pem

将以上三项设置为服务进程的环境变量后再启动。证书、私钥和 API 配置不加入源码包。
本次没有部署公网服务、配置证书或在用户真机联网验证。

三、主动整理文字
1. 在沟通页输入并显示文字，或加入明确标注的演示内容。
2. 打开“DeepSeek 智能整理”，选择最多六段已结束文字。
3. 查看将要发送的原文，勾选同意发送，再点击生成。
4. 实际生成会使用账户 API 额度；失败、超时、取消不自动重试。
5. 摘要仅作阅读辅助；候选信息卡需打开编辑器检查并保存。
   日期不完整时必须手动选择；保存不会自动标记“已核对”。
6. 待办建议需编辑保存，不会自动完成或安排通知。
7. 回应草稿点击后仅填入沟通输入框，显示或朗读由你再点击。
8. 原文变动、清空、切换演示、取消或离开整理页后，不沿用旧建议。
   选中文字变化后清除发送勾选，需再次检查。演示来源不会变成真实采集。
9. 发送仅包含选中段落的 ID、文字、来源和解析相对时间所需的参考时间、时区。
   音频、画面、事件库、联系人和其他未选记录不发送。

四、已验证与尚未验证
已完成：
- 90 个 Swift XCTest，其中包含声音特征、Core ML 输出、文字请求验证、来源保持、
  错误、超时、取消及过期输出处理；原有事件、存储、沟通、Watch 协议等检查继续通过。
- 8 个 Python 本地代理检查，覆盖配对、错误输入、限流、上游错误、超时及无自动重试。
  使用假密钥与模拟上游，不访问付费 API。
- 三种合成波形（静音、双音、衰减扫频）与 Google 固定版本 TensorFlow 对照。
  Swift 预处理最大绝对误差约 0.000881；Core ML float16 分数最大误差约 0.001575；
  三者首位类别一致。不是私人声音准确率、完整 AudioSet 评分或省电结论。
- Xcode 15.4 Debug 模拟器及 Release 通用 iOS 构建均成功，包含 Watch。
  iPhone 模拟器已安装并启动，首页显示“声音实验 · 公开样本，不用录音”。
  最低部署版本仍为 iOS 17.3 / watchOS 9.6。
