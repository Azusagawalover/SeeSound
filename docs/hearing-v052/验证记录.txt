见声 SeeSound 0.52 · 沟通与提醒
2026-11-04（北京时间）

检查范围与结果
iPhone 模拟器覆盖 7 条不同流程，iPad 模拟器覆盖 4 条不同流程。初轮手机 6 条通过、1 条失败；修正沟通页阅读状态与滚动位置后，针对失败流程在手机和 iPad 复查通过。重复执行不累计为新增用例。
Debug build-for-testing 与 Release 通用 iOS 构建通过，包含主应用、Watch 应用及分享扩展。版本 0.52 / build 52，最低 iOS 17.3、watchOS 9.6；实际界面运行环境为 Xcode 15.4 / iOS 17.5 模拟器。

本轮实际操作
手机：首页与四个主导航、面对面沟通、文字工作室、快捷回应、演示提醒确认、旅程核对与结果、精确搜索与恢复位置、公告导入到事务完成及恢复、最大辅助功能字号入口。
iPad：首页与四个主导航、快捷回应和演示提醒确认、最大辅助功能字号入口、原图缩放与可编辑对照。
新增整合流程检查快捷回应的原句、草稿返回后保留、固定阅读后显示新回应、切换后输入框和最新回应直接可见、声音页等待用户主动开始，以及同一演示事件确认后按钮消失且显示“已确认看到”。没有用自动滚动补救来掩盖分区切换问题。
另查看手机深色沟通页，补充选中分区的强调文字与边框；这属于外观检查，不计作额外功能用例。

发现与修正
1. 手机初轮停在“显示回应”：共用滚动容器保留旧的阅读位置，回应操作位于可见区域上方；检查脚本的泛用滑动也落在固定头部。产品修正为切换分区回到顶部，检查改为直接断言输入区和操作可见，保留原句比对。
2. 显示回应时若阅读画面固定，旧快照会遮住新文字。成功发送后清除固定快照并返回阅读区；失败时不丢弃原阅读状态或草稿。整合流程实际覆盖固定、选卡、显示及回到最新文字。
3. 深色外观下分区选中底色不够明显，增加强调文字和轮廓，不只依赖接近的底色。
初轮失败结果、修正后的复查结果分别保留，不把原失败记录改为通过。

边界
本轮集中修改界面、导航及上述显示状态，没有更换模型、API、资料保存格式或 Watch 消息协议，没有新增运行素材或第三方依赖。
没有进行真实麦克风／摄像头采集、付费 API 请求、真机安装、实际 Watch 收发／触觉、锁屏后台、能耗或目标用户研究。打开声音页等待开始按钮的检查，不等同于麦克风底层性能验证。
269 项数据检查是 0.51 的历史结果，本轮没有重新运行数据、模型或服务端全套检查；不计入 0.52 新检查数。大字号、VoiceOver、分屏与旋转也未穷尽。
事件确认与人工复核分别显示；Watch 连接和对应事件接收回执分别显示，本轮没有将可达写成已接收。
